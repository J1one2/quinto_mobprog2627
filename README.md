# quinto_labact1a

So first i created the assets folder then inside it is another folders name fonts icons and images, in the images it contains the images for the user profile image and the picture for the post. Then inside the lib folder i have two folders (screens & widgets). Inside screens I have home_screen.dart and newsfeed_screen.dart then for the widgets I have  action_button.dart, custom_text.dart, newsfeed_card.dart, post_image.dart, user_avatar.dart, constant.dart, main.dart. 

For the integration of the image in newsfeed_card.dart I first added the images itself to the assets/images folder and named it profile & console jpeg. so the console is the image for the post then i created a widget name post_image.dart where it takes the image path and displays it with rounded corners. Then inside the newsfeed_screen.dart i can edit the details of an post such as the user name, post description, date, and number of likes.
